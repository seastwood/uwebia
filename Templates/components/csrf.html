{# Site-wide CSRF plumbing. Include once inside on every base template. The app has hundreds of hand-written fetch() calls and dozens of forms, so rather than editing each call site we publish the token once and patch the three ways a state-changing request can leave the page: fetch, XHR, and form submission (both the submit event and the programmatic .submit() method, which does NOT fire that event). Anything same-origin and non-GET picks the token up automatically. #} {# A few views pass `csrf_token` in as an already-rendered string, which shadows Flask-WTF's global csrf_token() function for that template. Accept either shape so this include works no matter how it was reached. #}
