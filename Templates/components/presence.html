you place in the page context: () => ({ id: currentQuestionId, label: 'Question 3' }), }); `context` is polled on every beat, so it can just read whatever the editor already tracks — nothing to keep in sync. Polling, not push. The app runs on sync gunicorn workers with no Redis and no websocket layer, so in-memory presence would be per-worker (and therefore wrong), and a held-open SSE stream would occupy one of three workers for as long as somebody left an editor open. A small query every few seconds is what this deployment actually supports. #}
