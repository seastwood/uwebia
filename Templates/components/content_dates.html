{# When a guide or quiz was published, and whether it is still being kept up. A reader deciding whether to trust a page wants two different things: how old it is, and whether anyone still touches it. A date alone answers the first only if you subtract it from today, and answers the second not at all — so the published date is absolute ("12 Mar 2026") and the updated one relative ("3 days ago"), which is the form each question is actually asked in. `updated` is only worth showing when it says something the published date does not, so it is dropped when the two land on the same day — otherwise every freshly published guide would claim to have been updated. #} {% macro freshness(published, updated, compact=false) -%} {%- set _pub = published -%} {%- set _upd = updated if (updated and (not _pub or updated.date() != _pub.date())) else none -%} {%- if _pub or _upd -%} {%- if _pub %} Published {{ _pub | public_date }} {%- endif %} {%- if _upd %} Updated {{ _upd | time_ago }} {%- endif %} {%- endif -%} {%- endmacro %} {# Styles for the macro above. Included once per page that uses it. #} {% macro freshness_styles() -%} {%- endmacro %}
